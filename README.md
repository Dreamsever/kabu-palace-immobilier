# Kabu Palace Immobilier

Crée une page d'accueil d'agence immobilière haut de gamme pour Kabu Palace SARL à Kinshasa. Couleurs : bleu marine (#0F172A) et touches d'or (#D4AF37). Inclure un en-tête avec logo, un menu de navigation, une barre de recherche rapide (Acheter/Louer, Quartier, Type, Prix), une grille de 6 annonces de biens avec boutons WhatsApp directs, et un pied de page complet. Interface ultra-optimisée pour smartphone Android.
